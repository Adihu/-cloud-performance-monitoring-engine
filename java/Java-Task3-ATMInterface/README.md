# Java Task: ATM Interface

## Description
A secure command-line ATM (Automated Teller Machine) application built in Java. It simulates a banking system where users can authenticate with a User ID and PIN to manage their account balances, view transaction history, and transfer funds.

## Track
Java Development

## Features
- **User Authentication**: Secure login checking against pre-set User ID and PIN credentials.
- **Transaction History**: Keeps a live log of all deposits, withdrawals, and transfers made during the session.
- **Banking Operations**: 
  - Check current account balance.
  - Withdraw funds with built-in insufficient balance validation.
  - Deposit funds securely.
  - Transfer money to other accounts.
- **Interactive Menu**: Easy-to-use console menu loop.

## How to Run
1. Open your terminal or command prompt in the project directory.
2. Compile the Java file:
   ```bash
   javac ATMInterface.java
